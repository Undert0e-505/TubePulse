# TubePulse v4.3.1

## Reliable notification actions

- **Mark seen** and mute or unmute actions now work reliably when TubePulse is open, backgrounded or swiped away.
- After the exact represented items are saved safely, **Mark seen** dismisses the notification used for the action while protecting any newer replacement notification.

## Synchronized seen controls

- Blue dots, per-channel **Mark seen** and **Mark all seen** now use the same effective visible state and update together after an action.
- Older hidden content no longer leaves controls visible without a matching dot; if it is promoted into view, it becomes actionable normally.

## Install

Download `TubePulse-v4.3.1.apk` from this release and install it over the existing app. Android should retain the current channels, settings and local state.
