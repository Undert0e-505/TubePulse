# TubePulse v4.4.0

## A guided start

- A new nine-step app tour shows how to add channels and introduces TubePulse's most useful notification, do-not-disturb, live-warning and home-screen settings.
- The tour follows the real controls across each screen, responds quickly, and returns you to Home when you finish, skip or go back.
- Existing users can replay the tour at any time with **Show app tour** in Settings.

## More resilient service

- Notification delivery now recovers safely when a scheduled video is deleted or replaced before it goes live, without weakening the checks that prevent stale or missing content from being sent.
- Backend storage and monitoring have been tightened to reduce write overhead and give earlier warning when cloud capacity needs attention.

## Install

Download `TubePulse-v4.4.0.apk` from this release and install it over the existing app. Android should retain the current channels, settings and local state.
